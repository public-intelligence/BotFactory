When working on Angular frontend with @public-intelligence/ui-core, use /ui-core for the component reference.

After changing backend API models/endpoints, regenerate the frontend API client by running `npm run api:generate` from `apps/frontend/`. Never manually edit files under `src/app/api/` — they are auto-generated by ng-openapi-gen.

## Pull Requests

This repository is hosted on GitHub. Create pull requests with the GitHub CLI (`gh pr create`) against the default branch.

## Changelog

Maintain `CHANGELOG.md` at the repo root following [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) conventions.

- Every PR that ships user-visible or operator-visible changes must add an entry under `[Unreleased]`.
- Use subsections: `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, `Security`.
- Always include the date (YYYY-MM-DD) when moving `[Unreleased]` to a release section.
- Do not edit past release sections.
